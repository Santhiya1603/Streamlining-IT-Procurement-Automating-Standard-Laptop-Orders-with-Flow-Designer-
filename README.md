# Streamlining-IT-Procurement-Automating-Standard-Laptop-Orders-with-Flow-Designer-
Problem Statement
The current IT procurement process lacks efficiency and automation, resulting in delays and manual overhead, particularly in handling standard laptop orders. Requests for standard laptops often require configuration, but this step is prone to oversight or delay, leading to frustration among users and inefficient resource allocation within the IT department.

Milestone 1: Flow
Activity 1: Create a Flow to Create a Catalog Task
Create a ServiceNow Flow Designer flow that creates a Catalog Task for a Standard Laptop request. The task is configured for the Hardware assignment group and is created when the Service Catalog trigger conditions are met.
Milestone 2: Flow Assignment
Activity 1: Assign the Flow to the Standard Laptop Catalog Item
The Standard Laptop catalog item must use the newly created Flow instead of the other process engines. This ensures that requests for the Standard Laptop item use the automated Flow.
Milestone 3: Service Catalog
Activity 1: Place a Standard Laptop Order and Get Approvall
The Standard Laptop catalog item is used to place a service request through the Service Catalog. After submitting the request, the approval status and Requested Item record are verified. The associated Catalog Task is then checked to confirm that the Flow Designer automation has successfully created and assigned the task to the Hardware team.
Conclusion : 
By automating the standard laptop procurement process with ServiceNow's Flow Designer, the project effectively addresses inefficiencies and reduces manual overhead. This streamlined workflow ensures timely configuration of laptops, minimizes user wait times, and enhances overall productivity within the IT department. The implementation of this automated solution not only optimizes resource allocation but also significantly improves the user experience by providing a seamless and efficient procurement process.
